# Code Review: Memory Management Review

**Date:** 2026-04-24

## Summary
MetricsService shutdown is correctly wired into `app.on('before-quit')` in `src/main/main.js:634-643`, and every enabled plugin ships a `deactivate()`/`destroy()` pair. However, several leak vectors remain: `rlm-document-plugin` attaches five EventEmitter listeners in `activate()` that `deactivate()` never removes; `DocumentViewerComponent.destroy()` is a no-op despite binding eight DOM listeners and keeping rendered DOM alive; `ClaudeService.setPluginManager()` subscribes to `registry.on('plugin-event', …)` with no counterpart remover; and the CRE module's `shutdown()` only nulls `ctx`, leaving six generator/state references (`planGenerator`, `assertionGenerator`, `schemaManager`, `codeModel`, `risGenerator`, `introspector`) and the `initialized=true` flag dangling.

## Findings

- **[IMPORTANT]** LISTENER_NOT_REMOVED plugins/rlm-document-plugin/index.js:68 — `this.replManager.on('repl:initialized', …)` attached in `activate()`; `deactivate()` (line 122) nulls `replManager` but never calls `.off()` / `.removeAllListeners()` first.
- **[IMPORTANT]** LISTENER_NOT_REMOVED plugins/rlm-document-plugin/index.js:72 — `this.replManager.on('repl:closed', …)` attached in `activate()`, no matching removal in `deactivate()`.
- **[IMPORTANT]** LISTENER_NOT_REMOVED plugins/rlm-document-plugin/index.js:95 — `this.orchestrator.on('progress:update', …)` attached in `activate()`, no matching removal in `deactivate()`.
- **[IMPORTANT]** LISTENER_NOT_REMOVED plugins/rlm-document-plugin/index.js:99 — `this.orchestrator.on('query:iteration:start', …)` attached in `activate()`, no matching removal in `deactivate()`.
- **[IMPORTANT]** LISTENER_NOT_REMOVED plugins/rlm-document-plugin/index.js:103 — `this.orchestrator.on('query:complete', …)` attached in `activate()`, no matching removal in `deactivate()`.
- **[IMPORTANT]** EMPTY_DESTROY plugins/document-viewer-plugin/renderer/components/DocumentViewerComponent.js:901 — `destroy()` body is just a `console.log` comment "No cleanup needed currently" despite eight `addEventListener` calls at lines 819–853; container DOM and closure-bound handlers are not released.
- **[IMPORTANT]** LISTENER_NOT_REMOVED src/main/claude-service.js:240 — `registry.on('plugin-event', …)` bound inside `setPluginManager()`; the class exposes no `destroy()`/`shutdown()` and never calls `registry.off(...)`. Re-invoking `setPluginManager()` would duplicate the listener.
- **[IMPORTANT]** PARTIAL_STATE_RESET src/main/cre/index.js:199 — `shutdown()` only sets `ctx = null`; the module-level `planGenerator`, `assertionGenerator`, `schemaManager`, `codeModel`, `risGenerator`, `introspector` (declared lines 45–60) remain referenced and `initialized` (line 41) stays `true`, so a subsequent `initialize()` short-circuits at the `if (initialized) return` guard (line 132) and retains stale generators.
